# VoiceCare AI – Voice Enabled AI Medical Assistant

A voice-enabled AI-powered medical assistant web application built using Flask, Groq AI, Supabase, HTML, CSS, and JavaScript.
This project can be accesed through this link ---  https://medical-assistant-voice-featured.onrender.com/

# Team Project

This project was developed collaboratively as a group project for learning, innovation, and hackathon development purposes.

Team members contributed to:
Gowjesh - Frontend development,Voice assistant features
Sanjai Kumar - Backend Development and flask integration
Ponmani - AI chatbot functionality using Groq API
Prakash - Deployment and testing


# The system allows users to:
- Book doctor appointments
- Use voice commands for navigation
- Chat with an AI medical assistant
- Register doctors
- Login as doctors
- Store doctor details using Supabase
- Access pages through speech recognition

---

# Features

## AI Medical Chatbot
- Integrated with Groq AI API
- Provides intelligent medical guidance
- Real-time chatbot responses

## Voice Control System
- Speech recognition using Web Speech API
- Voice navigation across pages
- Voice-based form interaction
- Voice-enabled commands

## Doctor Management
- Doctor registration form
- Doctor login system
- Doctor listing page
- Appointment booking

## Responsive Frontend
- Clean medical-themed UI
- Mobile responsive design
- Flask template rendering

## Database Support
- SQLAlchemy integration
- SQLite database
- Supabase integration for cloud storage
